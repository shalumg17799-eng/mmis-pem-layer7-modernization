Summary

PRVDEAD1 is a legacy batch program originally designed to handle paper fingerprint card intake for high-risk providers. The program checks a hardcoded flag (permanently set to 'N') to determine whether to process paper fingerprint cards; since the flag is never enabled, the paper card processing logic is effectively unreachable and the program only displays a message directing users to use the LiveScan electronic fingerprinting system. This program has been functionally obsolete since the state transitioned to electronic LiveScan fingerprinting in 2019 and is no longer referenced or scheduled by any job.
- **Execution Environment**: Batch - **Database Access**: None - **MQ Calls**: No - **Module Type**: Main module
### Key Functionalities: 1: Paper Fingerprint Intake Initiation - Display program identification banner indicating this is the legacy paper fingerprint intake process for high-risk providers 2: Paper Fingerprint Processing Eligibility Check - Evaluate whether the paper fingerprint card processing feature is enabled or disabled before proceeding with any fingerprint intake workflow 3: LiveScan Redirection Notification - When paper fingerprint processing is disabled, notify users that the paper-based process is no longer active and direct them to use the LiveScan electronic fingerprinting system instead 4: Paper Fingerprint Card Mailroom Queue Logging - Log and register a paper fingerprint card submission into the mailroom queue for processing (legacy workflow, discontinued in 2019) 5: Paper Fingerprint Card Count Tracking - Maintain and display a running count of paper fingerprint cards that have been queued to the mailroom during the current processing session (legacy workflow, discontinued in 2019)
